# Parallels (SWSoft)

> Parallels is a virtualization and remote-access software company (founded as SWSoft in 1999, renamed Parallels in 2008, now part of Alludo/Corel). Its Parallels Remote Application Server (RAS) product ships a public REST API and a PowerShell SDK for automating farm administration. The API is served by the customer's self-hosted RAS server (default TCP port 20443) and authenticated with a session token.

## APIs

- [Parallels RAS REST API](https://docs.parallels.com/landing/ras-rest-api-guide): Manage a Parallels RAS farm — sites, secure gateways, RD session hosts, providers, publishing, policies and licensing. Base path api/<resource> on the RAS host at port 20443.
- [Parallels RAS PowerShell API](https://docs.parallels.com/landing/ras-powershell-api-guide): RASAdmin PowerShell module for scripting RAS administration.

## Authentication

- Log on: POST api/session/logon with JSON { username, password }; response returns authToken.
- Pass the token on every subsequent request via the auth_token request header.
- Version negotiated on Content-Type: application/json; api-version=1.0.
